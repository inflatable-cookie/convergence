# 028 GC

Status: complete
Updated: 2026-07-24

## Objective

Mark-and-sweep GC on the server, dry-run first: reclaim objects
unreachable after retention, never touching anything reachable.

## In Scope

- mark: roots = channel-head releases (and retained releases), retained
  bundles, current-window publications, lane heads + their snap lineage;
  walk manifests/recipes/blobs from each root (Merkle walk)
- retention integration: apply 8.2 evaluation to compute dropped
  releases/bundles/publications first; drop their metadata rows; then
  mark from what remains
- sweep: FsObjectStore listing (add `list(kind)` to the ObjectStore
  trait) minus marked set; grace window by file mtime (skip objects newer
  than N minutes — mid-upload safety)
- engine `gc(authz Admin, dry_run) -> GcReport {examined, reachable,
  dropped_metadata, swept, bytes}`; HTTP `POST /api/repos/:repo/gc`
  (admin; `?dry_run=true` default true); CLI `gc [--execute]`
- tests: reachable-never-collected invariant (publish/release/lane
  fixtures, run GC, everything still fetches/materializes), retention
  drop + sweep reclaims unreachable objects, dry-run mutates nothing,
  grace window respected

## Out Of Scope

- client-side store GC (thinned snap objects) — follow-up batch if needed
- verify (8.4)

## Acceptance Criteria

- exit-criterion test: GC reclaims unreachable objects and provably never
  touches reachable history; dry-run default

## Validation

- `effigy validate`
- `effigy qa:docs`

## Stop Conditions

- reachability semantics unclear for any root — doc 14/17 first

## Outcome

- `ObjectStore` gains `list` (id, bytes, mtime; skips temp files) and
  `delete`; metadata store gains repo listing, partition listing, and
  scoped delete operations
- `Engine::gc`: retention-driven metadata drops for the triggering repo
  (protection: surviving-release bundles + window bases), then a global
  mark across **all** repos (bundles, open publications, lane-head snap
  lineage, releases; Merkle walk incl. superposition variants and recipe
  chunks), then mtime-grace sweep; dry-run default
- `POST /api/repos/:repo/gc?dry_run` (admin), CLI `gc [--execute]`
- tests: orphans counted in dry-run without mutation then swept on
  execute; reachable-never-collected proven (channel head fetches +
  materializes byte-exact, lane pulls, post-GC); retention drop removes
  release rows while the channel head survives; non-admin denied
- 85 workspace tests green

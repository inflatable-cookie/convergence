# Contracts

One file per durable rule or interface. Each states the current rule, its
owner, and what depends on it. Add a line to the knowledge index for each new
contract.

| Contract | Scope |
| --- | --- |
| [working-rules.md](working-rules.md) | How work is executed |
| [release.md](release.md) | How a release is cut, verified, and withdrawn |
| [writing-style.md](writing-style.md) | Glue-light internal writing |
| [rust-quality-profile.json](rust-quality-profile.json) | Strict Rust quality profile and MSRV |
| [rust-quality-deviations.json](rust-quality-deviations.json) | Profile deviations |
